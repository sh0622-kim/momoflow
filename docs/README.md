## 유지 규칙

- 합의는 해당 내용을 소유하는 문서에 기록하고 다른 문서에서는 링크한다.
- 계획, 구현, 실제 검증을 구분한다. 문서 추가만으로 기능이 구현되었다고 표시하지 않는다.
- 동작이 바뀌면 관련 문서의 현재 상태도 갱신한다. 운영 정책 변경은 별도 변경으로 다룬다.
- 실행 로그와 개별 작업의 상세 경과는 GitHub 이슈의 작업 기록과 PR에 남긴다.
- 새 문서는 기존 문서에 담기 어려운 독립적인 목적이 있을 때만 추가한다.
